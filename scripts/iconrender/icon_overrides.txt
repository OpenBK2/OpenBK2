# Per-unit camera corrections shared by IconRender and the map editor.
# Compiled into SceneB2 as the default set. IconRender --overrides=FILE replaces
# it with a custom set; --overrides=none disables it.
#
# Most units keep the camera the model editor saved for their icon, which
# reproduces the shipped picture. These are the ones where it does not suit, or
# that never had one saved. One unit per line: the stats path, then the
# corrections, described at the top of IconRender/main.cpp:
#   frame           fill the window the way the shipped icons do
#   fill=F          with frame, the share of the window the longer side fills (0.93)
#   angle           turn to the view that best matches the shipped silhouette (frames too)
#   yaw=A pitch=A   set the angle; yaw+=D pitch+=D turn it by D degrees
#   distance*=K     move the camera K times further out
