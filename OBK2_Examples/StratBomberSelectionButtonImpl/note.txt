Required game-data work
Besides adding the button references to Mission_WindowScreenShared.xdb, you’ll need to:
Create Button05 for the strategic-bomber selector. It should be a normal one-state selector like buttons 1–3, invoke MissionSelectSpecialGroup, and have <Name>Button05</Name>.

Create Button06 for helicopters with <Name>Button06</Name> and the same MissionSelectSpecialGroup reaction.

Add or repoint the normal/pressed/disabled backgrounds and textures for Button05 and Button06.

Add tooltip references/localized text for strategic bombers and helicopters.

Also add buttons 5 and 6 to TopCenterPanel_WindowSimpleShared.xdb

No SUIConstsB2, action-button data, reinforcement definitions, or new UI reaction type is needed.
Until the UI data contains Button06, the new code and old UI database are intentionally incompatible: CMissionSuperWeapon::Init() now expects that named child.
